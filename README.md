# ⛺ 텐트리스 웨더 (Tentris Weather)

캠핑 자리(사이트) 크기와 7일 날씨 예보를 결합한 **캠핑 배치 & 날씨 가이드**입니다.
캠핑장을 고르고, 텐트·타프·화로대를 자리 위에 놓아 보면 바람·비·추위·불똥 위험과 챙길 준비물을 쉬운 말로 알려 줍니다.

누구나 쉽게 쓸 수 있도록 **큰 글씨, 큰 버튼, 4단계 진행 방식**으로 만들었습니다.

## 🚀 실행 방법

필요 환경: [Node.js](https://nodejs.org) 18 이상 (LTS 권장)

```bash
npm install
npm run dev      # 개발 서버 → http://localhost:5173
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## 🧭 사용 방법 (4단계)

| 단계 | 하는 일 |
| --- | --- |
| 1. 장소·날짜 | 지역 목록에서 고르거나, 이름·동네를 검색하거나, **내 위치**를 눌러 장소를 정합니다. 7일 예보 중 가는 날을 고릅니다. |
| 2. 자리 크기 | 자리 크기(작은/보통/큰 자리 버튼 또는 − + 버튼)와 바닥(데크/파쇄석/잔디)을 정합니다. |
| 3. 장비 놓기 | 텐트·타프·차량·화로대 등을 추가하고 끌어서 옮기거나 **방향 버튼**으로 움직입니다. 위험한 점은 바로 아래에 쉬운 말로 표시됩니다. |
| 4. 결과·준비물 | 바람·비·새벽 기온·이슬·별 보기·릴선을 한눈에 보고, 체크할 수 있는 준비물 목록을 받습니다. 카톡용 복사와 인쇄도 됩니다. |

## ✨ 주요 기능

- **전국 캠핑 지역 약 70곳 + 검색:** 경기·강원·충청·경상·전라·제주 지역별 목록과, 어떤 동네든 찾을 수 있는 장소 검색, 현재 위치 기반 조회를 지원합니다.
- **7일 예보:** [Open-Meteo](https://open-meteo.com) 무료 API(키 불필요)로 최저·최고 기온, 비 확률·강수량, 순간 풍속·풍향, 새벽 습도, 저녁 구름양, 해발고도를 가져옵니다.
- **장비 약 50종 + 검색:** 텐트(돔·백패킹, 원터치, 터널·거실형, 캐빈, 티피·벨, 쉘터·차박), 타프, 차량, 화로·그릴, 의자·테이블 같은 가구, 나무·바위·수돗가를 종류별 탭과 칩으로 고르거나 검색할 수 있습니다. 검색은 이름 외에 "가족", "차박", "숯불" 같은 비슷한 말과 여러 단어("화로 대형")도 찾습니다. 크기는 대략적인 값입니다.
- **AI 장비 규격 검색:** 3단계(장비 놓기) 화면 위쪽의 보라색 "AI로 장비 규격 찾기" 칸에 이름(예: "고투 머쉬룸 쉘터")을 넣고 "찾기"(또는 엔터)를 누르면, AI가 웹을 검색해 설치 크기를 찾아 줍니다. 참고한 페이지 링크와 확신 정도를 함께 보여주고, 숫자를 고친 뒤 **사용자가 확인해야** 저장됩니다. 출처가 없거나 말이 안 되는 크기는 서버에서 걸러 "못 찾음"으로 처리해 숫자를 지어내지 않게 했습니다. (아래 "AI 검색 설정" 참고)
- **AI 캠핑장 검색:** 1단계 "장소 찾기"에 캠핑장 이름(예: "가평 자라섬 캠핑장")을 쓰고 보라색 "AI로 캠핑장 찾기"를 누르면, AI가 웹에서 이름·주소를 찾고 위치를 알려 줍니다. AI가 알려준 좌표는 그대로 믿지 않고, 주소를 **별도 지도 데이터(OpenStreetMap Nominatim)** 로 찾은 위치와 비교해 크게 다르면 버립니다. 위치 근거는 "지도 자료와 맞춰 봄 / 주소로 찾음 / 시·군 중심 / 확인 못 함" 중 하나로 화면에 표시하고, 입력한 이름과 다른 곳을 골랐으면 경고합니다. 찾은 곳은 "내가 찾은 캠핑장"에 저장됩니다(이 기기·브라우저 기준).
- **내 텐트 저장:** 내 텐트 이름과 크기를 한 번 넣으면 브라우저에 저장돼 다음에도 목록에 남습니다(이 기기·브라우저 기준).
- **배치 시뮬레이터:** 끌어서 옮기기, 방향 버튼 이동, 90°/15° 회전, 시간대별 해 위치와 그림자.
- **쉬운 말 경고:** 자리 밖으로 나간 텐트, 텐트 줄이 자리 밖으로 나가는 경우, 바람이 장비 한계를 넘는 경우, 화로 불똥이 텐트로 날아갈 경우, 비·추위·이슬 맺힘.
- **맞춤 준비물:** 바닥 종류와 날씨, 배치에 따라 팩, 난방, 방수, 환기, 릴선 길이를 자동으로 추천합니다.

### 📱 반응형

휴대폰(390px), 태블릿(768px), PC(1440px) 화면에서 확인했습니다.

- 휴대폰: 헤더를 한 줄로 줄이고, 단계 버튼은 현재 단계만 이름을 보여줍니다. 하단 버튼은 짧게 "이전/다음"으로 표시하고, 아이폰 하단 안전 영역을 피합니다.
- 배치 지도는 화면 폭에 맞춰 자동으로 크기가 조절됩니다. 터치에서는 **장비 위에서만 끌기**가 되고 빈 배경은 화면 스크롤이 됩니다.
- 결과 카드와 7일 예보는 휴대폰에서 2~3열로 보여주고, 복사·인쇄 버튼은 가로로 꽉 차게 표시합니다.
- PC에서는 3단계에서 지도와 장비 목록을 좌우로 나란히 보여줍니다.

### 🎨 시각 표현

- 바닥 재질별 질감(데크 판자, 파쇄석, 잔디결)과 1m 격자, 축척 막대, 나침반
- 풍향·풍속에 따라 달라지는 바람 줄기 애니메이션
- 시간대에 따라 방향·길이가 변하는 장비 그림자
- 텐트 능선, 타프 접힘선, 출입구 표시, 일렁이는 화로 불빛

## 🤖 AI 검색 설정

AI 검색(장비 규격, 캠핑장 위치)은 브라우저가 아니라 **서버 함수**(`api/ai-lookup.ts`)가 호출합니다. API 키는 서버 환경변수에만 있고 브라우저나 GitHub에는 올라가지 않습니다. OpenAI 형식(`/chat/completions`)과 웹 검색 플러그인(`plugins: [{id: "web"}]`)을 지원하는 서비스에 연결하도록 만들어져 있습니다.

| 환경변수 | 설명 |
| --- | --- |
| `GNU_RAG_API_KEY` | API 키 |
| `GNU_RAG_API_BASE` | 서비스 주소 (예: `https://hello.timelygpt.co.kr/api/v2/chat/bridge/openai`) |
| `GNU_RAG_API_MODEL` | 모델 이름 (예: `anthropic/claude-sonnet-5.5`) |

- **내 PC에서:** `.env.example` 을 `.env` 로 복사해 값을 채운 뒤 `npm run dev`. 개발 서버가 같은 주소(`/api/ai-lookup`)를 처리합니다. 키가 없어도 앱은 동작하고 AI 검색 버튼만 "아직 켜져 있지 않아요"라고 알려 줍니다.
- **Vercel에 배포:** GitHub 저장소를 Vercel에서 Import → Settings → Environment Variables 에 위 3개를 입력 → Deploy. `api/` 폴더는 자동으로 서버 함수가 됩니다.

**비용 보호:** 서버에서 IP당 시간당 20회, 하루 전체 400회(장비·캠핑장 합산)로 제한하고 같은 질문은 24시간 동안 캐시합니다. 다만 서버리스는 인스턴스마다 횟수를 따로 세기 때문에 "대략적인" 방어선입니다. 공개 배포 시에는 키를 발급한 서비스 쪽에서도 사용 한도(예산)를 걸어 두세요.

## 🧮 계산 방식 요약

- **이슬점(근사):** `이슬점 = 새벽 기온 − (100 − 습도) / 5`. 습도 80% 이상이거나 기온과 이슬점 차가 2.5℃ 이하면 "이슬 많음".
- **불똥 판정:** 화로 → 텐트/타프 방향과 바람 방향의 내적이 0.55 초과, 거리 3.6m 미만.
- **바람:** 순간 풍속이 장비별 한계(타프 약 8.5~10m/s, 텐트 약 12~15m/s) 이상이면 위험. 8m/s 이상은 주의.
- **릴선:** 배전반~텐트 직선거리 × 1.25 (여유분).
- **별 지수:** `100 − 저녁 구름양 × 0.8` (습도 85% 초과 시 −15), 10~100점.
- 예보 기온은 입력한 좌표의 해발고도가 이미 반영된 값이라 고도 보정을 따로 하지 않고, 해발고도는 참고용으로 표시합니다.
- API의 풍향은 "불어오는 쪽"이라 화면에서는 반대(향하는 쪽)로 변환해 그립니다.
