# ⛺ 텐트리스 웨더 (Tentris Weather)

캠핑 사이트 규격(데크/파쇄석/잔디)과 실시간 기상 데이터를 결합한 **2D 스마트 피칭 & 웨더 시뮬레이터**입니다.
텐트·타프·화로대를 사이트 위에 직접 배치해 보고, 풍향·돌풍·결로·고도 기온을 반영한 위험 경고와 준비물 목록을 자동으로 받아볼 수 있습니다.

## 🚀 실행 방법

필요 환경: [Node.js](https://nodejs.org) 18 이상 (LTS 권장)

```bash
npm install
npm run dev      # 개발 서버 → http://localhost:5173
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## ✨ 주요 기능

| 기능 | 설명 |
| --- | --- |
| 실시간 기상 연동 | [Open-Meteo](https://open-meteo.com) 무료 API(키 불필요)로 캠핑장 위치의 풍향·돌풍·기온·습도·구름량을 한 번에 불러옵니다. |
| 드래그 & 회전 배치 | 텐트, 타프, 차량, 화로대, 나무, 배전반을 끌어서 옮기고 15° 단위로 회전합니다. 내 텐트 규격도 직접 입력할 수 있습니다. |
| 가이로프·데크 이탈 경고 | 본체나 스트링 영역이 사이트 밖으로 나가면 경고하고, 데크펙+단조펙 혼합 사용을 추천합니다. |
| 불티 위험 경고 | 바람이 화로대에서 텐트 쪽(풍하측)으로 불면 불빵 위험을 알립니다. |
| 릴선 길이 계산 | 배전반과 텐트 사이 거리에 여유 25%를 더해 10/20/30m 릴선을 추천합니다. |
| 고도 보정 & 결로 지수 | 해발 100m당 -0.65℃ 보정한 새벽 체감온도, 이슬점 기반 결로 위험도, 별보기 지수를 계산합니다. |
| 맞춤 장비 추천 | 배치와 날씨에 따라 팩, 난방, 환기, 릴선 준비물을 자동 생성하고 필수 항목을 강조합니다. |

### 🎨 시각 표현

- 바닥 재질별 질감: 우드 데크(판자), 파쇄석(자갈), 잔디/노지(풀결)와 1m 격자
- 풍향·풍속에 따라 방향·밀도·속도가 달라지는 바람 줄기 애니메이션
- 태양 시간대(08~18시)에 따라 방향과 길이가 변하는 장비 그림자
- 텐트 능선, 타프 접힘선, 일렁이는 화로 불빛 등 장비 종류별 표현
- 나침반(북쪽 고정, 바람 방향 표시)과 축척 막대

## 🗂️ 프로젝트 구조

```
src/
├─ App.tsx      # 화면, 캔버스 인터랙션, 기상·배치 분석 로직
├─ presets.ts   # 장비 프리셋, 캠핑장 위치/해발고도 데이터
├─ index.css    # 바닥 질감, 바람, 그림자 등 커스텀 스타일
└─ main.tsx     # 진입점
```

## 🧮 계산 방식 요약

- **고도 보정:** `체감 최저기온 = 예보 최저기온 − (해발고도 / 100 × 0.65)`
- **이슬점(근사):** `이슬점 = 체감 최저기온 − (100 − 습도) / 5`
- **불티 판정:** 화로 → 텐트 방향 벡터와 풍향 벡터의 내적이 0.55 초과, 거리 3.6m 미만
- **별 지수:** `100 − 구름량 × 0.8` (습도 85% 초과 시 −15), 10~100점
